## Описание проекта
Проект представляет собой консольную игру про фермера. В ходе лабораторной работы код был полностью отрефакторен: логика разбита на отдельные модули (`.c` и `.h`), а все разрозненные переменные упакованы в структуры (`Player`, `Map`, `EquipmentSlot`).

## Реализованный функционал
1. **Структуры данных:** `struct Player` (характеристики, координаты, инвентарь, экипировка) и `struct Map` (двумерный динамический массив).
2. **Перечисления (enum):** используются для пунктов меню (`MenuCode`) и типов экипировки (`EquipType`).
3. **Жизненный цикл героя:** персонаж создается динамически через меню. Реализована проверка на существование (`if (player == NULL)`), пересоздание с очисткой памяти (`free()`) и выводом адреса в консоль.
4. **Управление временем:** подменю с просмотром часов, ожиданием (с блокировкой перехода через 02:00 ночи) и сном (восстановление сил на следующий день).
5. **Экипировка:** 3 слота (Голова, Тело, Обувь). При надевании/снятии вещей динамически пересчитываются `max_hp` и `max_stamina`.
6. **Приключение:** генерация этажей, пошаговое перемещение (WASD), HUD (HP, выносливость, золото, этаж, время), механика хрупкого пола. Трата выносливости, награда золотом за этаж и экстренная эвакуация при 0 HP или в 02:00.
